# 微部落 #

**发布上线，不过可以升级迭代**

集信息与娱乐于一体的网站，提供发布博客、等服务

如果你也想弄个社交博客，微博客或许是你的不二选择！

## 特点欣赏 ##
* 自动登录 *用户登录的时候浏览器自动获取登录信息，因为服务器存储会话实现自动登录*
* 电子邮件支持 *用户使用邮箱注册的时候服务器发送邮件通知，因为服务器通信方法是电子邮件*
* 分页功能 *用户浏览帖子的时候服务器返回数据，因为服务器限制帖子的数量*
* 用户通知 *用户私信的时候服务器转发消息，因为服务器实时通知对方*
* 追随者 *我受到欢迎的时候，我希望帖子合并在一起，如果大家关注可选，*
* 个人主页 *我发布帖子的时候遭受他人的讨厌时，因为他人总是恶意评论。我一个人感到既孤单又惆怅，因为我需要他人的友情*
* ElasticSearch展示全文搜索的信息 *展示搜索热度最高的，对每次搜索的词语热度+1*
* 用户编程接口 *客户端开发的时候服务器认证、操作帖子，因为服务器开放用户编程接口*
* 后台作业 *用户导出全部帖子的时候服务器处理大量数据，因为服务器交给celery任务队列。*
*
